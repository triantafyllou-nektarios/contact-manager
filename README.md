# Contact Manager

A simple command-line Contact Manager built with Python.

## Features

- Add new contacts
- View all saved contacts
- Search for a contact by name
- Delete contacts
- Save contacts to a text file
- Load saved contacts when the program starts
- Validate user input
- Handle invalid input with `try/except`

## Technologies

- Python
- Git
- GitHub

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run:


python main.py
